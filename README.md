# Data Science – Course Page

Course website for Data Science, Dept. of Information Technology, JNTUGV-CEV.

## Files
- `index.html` – the course page
- `static/` – photos and college logo

## How to edit
Open `index.html` in a text editor  Change the text, links and photo file names beside each marker.

## Add a link
Copy one line in the Quick Links section and change the address and name:

```html
<li><a href="https://drive.google.com/your-link">Unit 1 – Slides</a></li>
```

## Publish
Upload `index.html` and the `static` folder to GitHub Pages or Netlify.
