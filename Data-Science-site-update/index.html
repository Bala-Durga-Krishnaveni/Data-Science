Course Description   This course introduces the Python ecosystem for data science. Topics include: Python fundamentals and object-oriented programming; GUI and internet programming; numerical computing and data analysis with NumPy and Pandas; data preprocessing; and data visualization with Matplotlib. Each topic comes with slides, worksheets, study notes and illustrated comics.
